# TelegramBot — відключення води (voda.uz.ua)

Бот на TypeScript + grammY. Парсить новини КП «Водоканал м. Ужгород» (https://voda.uz.ua/)
і сповіщає підписників, коли з'являється відключення по їхній вулиці/району.

> Дані беруться через WordPress REST API сайту (`/wp/v2/posts`), а не скрейпінгом HTML.
> Потрібен Node >= 24 (використовується вбудований `node:sqlite`, він друкує ExperimentalWarning).

## Запуск
```
cp .env.example .env   # вписати BOT_TOKEN
npm install
npm run dev            # розробка (tsx watch)
npm run build && npm start   # продакшн
```

Запускайте лише один екземпляр бота на токен (long polling + спільна SQLite-база).

## Налаштування (`.env`)
- `BOT_TOKEN` — токен від @BotFather (обов'язково)
- `DB_PATH` — файл SQLite, за замовчуванням `./data/bot.db`
- `POLL_INTERVAL_MIN` — інтервал опитування сайту, хв (>= 15, за замовчуванням 30)

## Команди бота
`/start`, `/subscribe [вулиця]` (без аргументу бот сам попросить назву; 3–50 символів, до 10 підписок), `/unsubscribe <вулиця>`, `/list`, `/schedule`, `/history`, `/lang uk|ru`

`/history` — історія відключень по ваших підписках за 7, 30 або 90 днів (період обирається кнопками; без підписок історії немає).

### Кнопки
`/start` показує постійну клавіатуру: «Історія», «Актуальні», «Підписки», «Налаштування» (кнопки діють як `/history`, `/schedule` і два екрани нижче).
- **Підписки** — одне повідомлення з кнопкою 🗑 на кожну підписку (видалення правкою того ж повідомлення) і «➕ Додати» (бот просить назву вулиці). Те саме відкриває `/unsubscribe` без назви.
- **Налаштування** — вибір мови кнопками з позначкою ✅; клавіатура внизу оновлюється на нову мову. Те саме відкриває `/lang` без значення.
- Команди з аргументом (`/subscribe <вулиця>`, `/unsubscribe <вулиця>`, `/lang ru`) працюють як раніше. Будь-який інший текст отримує підказку.
- Меню команд Telegram (кнопка «/» біля поля вводу) бот виставляє під час запуску; мова меню залежить від мови інтерфейсу Telegram, а не від вибору в боті. Telegram кеширує меню й клавіатуру, тож зміни видно після повторного відкриття чату або нового `/start`.

Мова за замовчуванням — українська; російську можна обрати командою `/lang ru`.
Перший опит після створення бази лише запам'ятовує поточну стрічку без розсилки.

## Перевірка без токена
```
npm run check
```
Парсер на живому сайті, база (`Store`), матчинг підписок, форматування, статуси й дати, вікна історії 7/30/90 днів, підписи кнопок меню, екрани підписок і налаштувань.
Результат залежить від поточної стрічки сайту.

## Структура
- `src/parser/` — парсинг voda.uz.ua → `Outage[]`
- `src/db/` — SQLite (`node:sqlite`)
- `src/scheduler.ts` — періодичний опит і diff
- `src/notify.ts` — матч підписок і відправка
- `src/commands/` — команди grammY
- `scripts/check.ts` — перевірка без Telegram
