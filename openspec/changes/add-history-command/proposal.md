# Proposal

## Why

`/schedule` показывает только актуальные отключения из последних 20 постов сайта, а в базе нет ни заголовков, ни дат прошлых событий. Пользователь не может посмотреть, что происходило по его улице за последние недели, например проверить, как часто там бывают аварии. Сайт хранит архив, и его можно запрашивать по датам, поэтому историю можно дать без хранения данных у себя.

## What Changes

- Новая команда `/history`: бот предлагает выбрать период кнопками (7 / 30 / 90 дней) и показывает отключения за него.
- История строится по подпискам пользователя, как и поиск по ключевым словам в `/schedule` (слово ищется в заголовке и теле поста). Без подписок бот объясняет, что история строится по подпискам, и подсказывает `/subscribe`.
- Максимальный период 90 дней. Свободный выбор периода и произвольные даты не входят в эту версию.
- В записях истории показываются дата (по `Europe/Kyiv`) и заголовок со ссылкой. Значок статуса виден только у свежих постов, у старых его нет, потому что сайт не всегда правит заголовок после завершения работ.
- Парсер получает запрос отключений за период (`after`, постраничная загрузка) вместо одного запроса на 20 постов. Источник скрыт за одной функцией, чтобы позже его можно было заменить на собственную таблицу в SQLite.
- В боте появляется обработка нажатий inline-кнопок (`callback_query`).
- Тексты на украинском и русском, как у остальных команд.

## Capabilities

### New Capabilities
- `outage-history`: просмотр истории отключений за выбранный период по подпискам пользователя через команду `/history`: выбор периода кнопками, ограничение 90 днями, формат записей, поведение без подписок и без результатов.

### Modified Capabilities

Нет: в проекте пока нет ни одной спецификации, поведение остальных команд не меняется.

## Impact

- **Код:** `src/parser/voda-uz.ts` (запрос за период, постраничная загрузка, кэш по периоду), новый `src/commands/history.ts`, регистрация в `src/bot.ts`, тексты в `src/i18n.ts`, общий форматтер дат и записей.
- **Внешний сервис:** дополнительные запросы к REST API voda.uz.ua (до 1–2 страниц на нажатие кнопки), смягчённые кэшем.
- **База данных и зависимости:** не меняются.
- **Проверка:** `scripts/check.ts` дополняется проверками запроса за период, границы 90 дней и форматирования. Сценарий в самом Telegram проверяется вручную.
- **Не входит:** собственное хранилище истории (запасной вариант на будущее), свободный выбор дат и периодов, постраничный показ длинных результатов.
