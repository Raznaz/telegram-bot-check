# Proposal

## Why

Сейчас всё управление ботом идёт командами, которые нужно помнить и набирать: `/unsubscribe` без названия не работает как диалог (обычное сообщение бот игнорирует), у `/lang` без аргумента кликабельна лишь команда, а не значения, список команд в меню Telegram пуст, поэтому `/history` там не видна. У похожих ботов те же действия делаются нажатиями: постоянные кнопки внизу, экраны с кнопками, правка сообщения на месте. Пользователям бота это привычнее, и три найденные неудобства закрываются одним решением.

## What Changes

- **Постоянная клавиатура** под полем ввода из четырёх кнопок: «Історія», «Актуальні», «Підписки», «Налаштування». Показывается в ответе на `/start`, подписи на языке пользователя.
- **Экран «Підписки»**: сообщение с кнопкой «видалити» у каждой подписки и кнопкой «Додати». Удаление правит сообщение на месте, без нового. Удалить можно только подписку своего чата.
- **Экран «Налаштування»**: выбор языка кнопками с отметкой текущего. При смене языка экран правится на месте, а клавиатура внизу обновляется на новый язык.
- **Команды продолжают работать**: `/subscribe`, `/unsubscribe <назва>`, `/lang uk|ru`, `/list`, `/schedule`, `/history`. Меняется только поведение без аргумента: `/unsubscribe` открывает экран подписок, `/lang` открывает экран настроек.
- **Меню команд Telegram** выставляется ботом при запуске (список всех команд, украинский по умолчанию, русский для клиентов с русским интерфейсом), поэтому `/history` появляется в нём автоматически.
- **Подсказка на непонятный текст**: если бот ничего не ждёт и сообщение не команда и не кнопка, он коротко отвечает, как пользоваться меню, а не молчит.
- Нажатие кнопки главного меню отменяет ожидание названия улицы, как это делает команда.
- Кнопки «Історія» и «Актуальні» запускают существующие сценарии `/history` и `/schedule` без изменения их поведения.

## Capabilities

### New Capabilities
- `bot-menu`: кнопочная навигация бота: главная клавиатура, экраны подписок и настроек, поведение команд без аргументов, меню команд Telegram и реакция на неизвестный текст.

### Modified Capabilities

Нет: в проекте пока нет архивных спецификаций (спецификация `outage-history` ещё в неархивированном change `add-history-command`), а её требования эта работа не меняет.

## Impact

- **Код:** новый `src/menu.ts` (клавиатура, подписи, распознавание кнопок), правки `src/bot.ts`, `src/index.ts` (меню команд при запуске), `src/commands/start.ts`, `unsubscribe.ts`, `lang.ts`, `subscribe.ts`, `history.ts`, `schedule.ts`, `src/i18n.ts`, `README.md`, `scripts/check.ts`.
- **База данных:** не меняется (ни схема, ни `Store`). Кнопка «видалити» опознаёт подписку по короткому хэшу её названия среди подписок этого же чата.
- **Зависимости:** новых нет, нужны `Keyboard`, `InlineKeyboard`, `callbackQuery`, `hears`, `setMyCommands` из уже установленного grammY.
- **Для существующих пользователей:** постоянная клавиатура появится после следующего `/start` или смены языка. Массовая рассылка клавиатуры не планируется.
- **Связь с другим change:** `add-history-command` (задача 4.2, ручная проверка) пока не завершён; эта работа не меняет поведение `/history`, только добавляет кнопку, которая её запускает.
- **Не входит:** картинки и инфографика, уведомления по расписанию, кнопочный выбор периода истории с отметкой выбранного, кнопки в самих уведомлениях, веб-приложение внутри Telegram.
